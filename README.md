## Dependências

O projeto utiliza as seguintes bibliotecas e ferramentas:

### Backend (API)

Express  
Sequelize  
pg-promise  
bcrypt  
jsonwebtoken  
Passport  
passport-jwt  
passport-local
CORS  
dotenv
Nodemon

### Frontend

React  
React DOM  
Vite  
React Router DOM  
Material UI  
Material UI Icons
Emotion React  
Emotion Styled  
Axios  
Bootstrap  
Recharts  
ESLint

As dependências estão declaradas nos arquivos `package.json` de cada diretório e suas versões resolvidas estão registradas nos arquivos `yarn.lock`.

### Instalação das dependências

O projeto utiliza Yarn para gerenciamento das dependências.

cd Api

yarn install

cd frontend

yarn install
